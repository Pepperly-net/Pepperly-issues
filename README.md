# Pepperly issues tracker

> [!WARNING]
> ## This repository is focused on issues; it doesn't contain any code itself.

## Reporting usual issues

Use the Issues section to publish your Bug or Suggestion.

## Reporting Security Issues

For Security issues, please send an email to security@pepperly.net

Please include as much of the information listed below as you can to help us better understand and resolve the issue:
- The type of issue (ex: buffer overflow, SQL injection, or cross-site scripting)
- The URL where the problem was found
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

**Please do not report security vulnerabilities through public GitHub issues or discussions!**
